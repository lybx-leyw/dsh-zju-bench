# 学习面板接入记录

更新：2026-10-08。

## 产物语义

终稿是三阶段解析结果，保留字幕、分块、时间、页面和主支线标签。讲义只从主线块填充 PPT 知识树；未覆盖知识点仍保存在知识树中。讲义终审 v2 使用原生 DSH Agent，可整节重组、改名与拆分合并节点。原稿 ref 跟踪承接关系，终稿 src 跟踪证据，页码和时间从来源计算。终稿与原始 PPT 知识树独立保存。

学习面板提供终稿、讲义、PPT、字幕四个独立视图。讲义使用结构化章节、语义配色、Markdown 与公式渲染，三级目录可折叠定位，例题解答可折叠，块级来源可跳回终稿。最近三次终审的上一版可恢复。

## 存储和并发

产物统一进入宿主 knowledge 域，按账号、课程、课节隔离；旧文件可自动迁移。终稿版本变化会清除旧讲义及终审，讲义重新生成会清除旧终审。同一课节的写操作互斥，注销与卸载会取消操作，失败保留已有产物。字面检索可指定 final / lecture / all 来源层，不混称原文与讲义。
