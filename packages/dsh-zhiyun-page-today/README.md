# dsh-zhiyun-page-today

「今天」页：日程、插空任务与最近进度的落点。

**改这一页的东西都在这里**：页头文案、空状态骨架、「接下来 / 插空完成 / 最近在看」三块。后续要加的**日历组件、计划创建组件**也属于本包 —— 这正是当初把页面拆成独立包的原因。

## 边界

- 只依赖 `slots`（注册页面内容必需）。导航控制器由外壳在 `renderSlot` 的 owner 参数里交过来（`{ controller }`），所以本包不认识任何具体服务名 —— 页面与外壳之间只有「外壳声明插槽、页面填内容」一条边。
- 当前没有领域依赖（不取 `zhiyunStudyController`）：这一页还没有课程与计划的数据源，呈现的是空状态。
- 没有自己的样式表：页面用的是外壳的 `.zy-*` 类（外壳永远在场）。

## 插槽

在 `zhiyun.today.content` 注册内容。声明 `children` 的是外壳（声明即认领），本包只注册。要临时接管这一页做验证，另建一个插件以更高 `priority` 注册同名插槽即可（`scripts/test-host.mjs` 就是这么验证「我的课」的）。
